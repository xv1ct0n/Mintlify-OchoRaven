Capture the Flag competitions are one of the fastest ways to level up your cybersecurity skills. Instead of passively absorbing theory, you're dropped into gamified environments where you must actively exploit vulnerabilities, reverse-engineer binaries, crack cryptographic puzzles, and analyze forensic artifacts to capture a flag — a hidden string that proves you solved the challenge. CTFs build the problem-solving instincts and technical fluency that structured courses alone simply cannot replicate.

## Always-On CTF Platforms

These platforms host permanent challenge libraries you can tackle any time, at your own pace — no registration deadline, no waiting for a competition window.

<CardGroup cols={2}>
  <Card
    title="PicoCTF"
    icon="flag"
    href="https://picoctf.org"
  >
    Developed by Carnegie Mellon University's security research team, PicoCTF is the ideal first CTF experience. Challenges are thoughtfully scaffolded for beginners and cover web exploitation, cryptography, forensics, reverse engineering, and binary exploitation.
  </Card>
  <Card
    title="CTFtime"
    icon="calendar"
    href="https://ctftime.org"
  >
    CTFtime is the central directory for the global CTF community. It lists hundreds of upcoming competitions every year, tracks team rankings, and archives past challenges so you can practice on real competition problems long after the event ends.
  </Card>
  <Card
    title="RootMe"
    icon="terminal"
    href="https://root-me.org"
  >
    With over 400 challenges spanning web, network, cryptography, steganography, and exploitation, RootMe gives you an enormous breadth of practice material. A points-based system and active community leaderboard keep the experience competitive and motivating.
  </Card>
  <Card
    title="OverTheWire"
    icon="server"
    href="https://overthewire.org"
  >
    OverTheWire's wargames are legendary for teaching Linux command-line fundamentals and security concepts simultaneously. Starting with Bandit — designed for the absolute beginner — each game builds on the last, gradually introducing more complex exploitation techniques.
  </Card>
</CardGroup>

## Guided Lab Environments

These environments give you a vulnerable target you control locally or online, letting you practice exploitation techniques safely and legally without the competitive pressure of a timed CTF.

<CardGroup cols={2}>
  <Card
    title="OWASP WebGoat"
    icon="bug"
    href="https://owasp.org/www-project-webgoat/"
  >
    WebGoat is a deliberately insecure web application maintained by OWASP. Each lesson teaches you how a specific vulnerability works — SQL injection, XSS, CSRF, and more — and then challenges you to exploit it yourself within a guided, interactive interface.
  </Card>
  <Card
    title="DVWA"
    icon="shield-halved"
    href="https://dvwa.co.uk"
  >
    The Damn Vulnerable Web Application is a classic PHP/MySQL app intentionally riddled with common vulnerabilities. You can tune the security level from low to impossible, making it an excellent tool for both beginners learning the basics and advanced learners refining bypass techniques.
  </Card>
  <Card
    title="VulnHub"
    icon="download"
    href="https://vulnhub.com"
  >
    VulnHub hosts a massive collection of free, downloadable virtual machine images — each one a purposely vulnerable system waiting to be compromised. Import them into VirtualBox or VMware and practice full penetration test workflows from reconnaissance all the way through post-exploitation.
  </Card>
  <Card
    title="HackTheBox Starting Point"
    icon="play"
    href="https://hackthebox.com"
  >
    Starting Point is Hack The Box's free onboarding track for beginners. It walks you through a series of guided machines with detailed question prompts, teaching you the HTB methodology and foundational enumeration and exploitation techniques step by step.
  </Card>
</CardGroup>

<Note>
  Before practicing on any vulnerable lab environment — especially locally hosted VMs — make sure you've set up a **dedicated, isolated lab network**. Run vulnerable machines on a host-only or NAT-only network adapter in VirtualBox or VMware so they are never exposed to your home network or the internet. A vulnerable machine that's reachable from outside your lab is a real security risk, not just a training one.
</Note>
