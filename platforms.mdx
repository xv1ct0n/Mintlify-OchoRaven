The cybersecurity learning landscape has never been more accessible. Today, you can build real, job-ready skills without spending a single dollar — thanks to a growing ecosystem of platforms that offer browser-based labs, guided learning paths, video courses, and hands-on challenges. Whether you're picking up a keyboard for the first time or sharpening an existing skill set, the platforms below give you everything you need to get started and keep growing.

<CardGroup cols={2}>
  <Card
    title="TryHackMe"
    icon="shield"
    href="https://tryhackme.com"
  >
    The most beginner-friendly entry point in the industry. TryHackMe runs entirely in your browser — no local setup required. Structured learning paths walk you from absolute zero to job-ready skills across offensive and defensive security topics.
  </Card>
  <Card
    title="Hack The Box"
    icon="cube"
    href="https://hackthebox.com"
  >
    The go-to platform for intermediate and advanced practitioners. HTB's free tier gives you access to retired machines and challenges that mirror real-world penetration testing scenarios. Expect to be challenged.
  </Card>
  <Card
    title="Cybrary"
    icon="graduation-cap"
    href="https://cybrary.it"
  >
    A comprehensive library of video-based courses covering everything from networking fundamentals to advanced threat hunting. Cybrary's free tier is especially useful for certification prep, including CompTIA, CEH, and CISSP.
  </Card>
  <Card
    title="SANS Cyber Aces"
    icon="star"
    href="https://cyberaces.org"
  >
    SANS is one of the most respected names in cybersecurity training, and Cyber Aces is their gift to the community. These free foundational courses cover operating systems, networking, and system administration — the bedrock of any security career.
  </Card>
  <Card
    title="Open Security Training 2"
    icon="lock"
    href="https://opensecuritytraining.info"
  >
    If you want university-level depth without the tuition bill, OpenSecurityTraining2 delivers. Topics range from architecture and low-level exploitation to malware analysis and reverse engineering — all taught with rigorous technical detail.
  </Card>
  <Card
    title="PortSwigger Web Security Academy"
    icon="globe"
    href="https://portswigger.net/web-security"
  >
    Built by the creators of Burp Suite, the Web Security Academy is widely considered the best free resource for web application security. Every topic includes theory, interactive labs, and solutions — completely free, no account required to read.
  </Card>
</CardGroup>

## Platform Comparison

Use this table to match your current skill level and learning goals to the right starting point:

| Platform | Focus | Skill Level | Free Tier Limits |
|---|---|---|---|
| TryHackMe | Offensive & Defensive | Beginner → Intermediate | Some rooms require a subscription |
| Hack The Box | Penetration Testing | Intermediate → Advanced | Active machines locked; retired machines free |
| Cybrary | Video Courses & Cert Prep | Beginner → Advanced | Course library partially paywalled |
| SANS Cyber Aces | Fundamentals | Beginner | Fully free, limited course catalog |
| Open Security Training 2 | Low-level & Technical | Intermediate → Expert | Fully free, self-paced |
| PortSwigger Web Security Academy | Web Application Security | Beginner → Advanced | Fully free, all labs included |

<Tip>
  If you're an absolute beginner with no prior IT background, start with **TryHackMe** — its guided paths and in-browser labs remove every setup barrier so you can focus entirely on learning. If web security is your primary interest, go straight to **PortSwigger Web Security Academy**, which offers the most structured and comprehensive free curriculum available anywhere for that domain.
</Tip>
