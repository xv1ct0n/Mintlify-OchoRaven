Cloud security is one of the fastest-growing areas in the entire cybersecurity industry. As organizations shift workloads to AWS, Azure, and GCP at an accelerating pace, the demand for professionals who understand cloud-native attack surfaces has exploded. Misconfiguration remains the number one cause of cloud breaches — overly permissive IAM policies, publicly exposed storage buckets, and unencrypted data at rest continue to make headlines — which means even entry-level cloud security skills have immediate real-world impact.

## Resources by Cloud Platform

The three major cloud providers each have distinct services, terminology, and security models. Use the tabs below to explore provider-specific training resources, then check the cloud-agnostic section for credentials and tools that span all three.

<Tabs>
  <Tab title="AWS">
    ### AWS Security Training Resources

    Amazon Web Services is the market leader in cloud computing and offers some of the best security-focused training materials available, much of it free.

    **Official Training**
    - **AWS Security Training & Certification** ([aws.amazon.com/training](https://aws.amazon.com/training)) — AWS's own learning platform includes free digital courses covering IAM, VPC security, GuardDuty, Security Hub, and more. The paid AWS Certified Security – Specialty exam is the gold-standard AWS security credential.

    **Hands-On Labs**
    - **CloudGoat** ([github.com/RhinoSecurityLabs/cloudgoat](https://github.com/RhinoSecurityLabs/cloudgoat)) — A deliberately vulnerable AWS environment created by Rhino Security Labs. You deploy intentionally misconfigured AWS infrastructure and practice attacking and remediating real cloud misconfigurations. Free and open source.
    - **Flaws.cloud** ([flaws.cloud](http://flaws.cloud)) — A free, guided challenge where you exploit real AWS misconfigurations to progress through levels. Created by Scott Piper, it covers S3 bucket exposure, metadata service abuse, and IAM privilege escalation.

    **Reference Architecture**
    - **AWS Well-Architected Framework — Security Pillar** — AWS's own best practices documentation for building secure cloud workloads. Invaluable for understanding how AWS expects customers to design secure environments, and frequently referenced in security assessments.
  </Tab>
  <Tab title="Azure">
    ### Azure Security Training Resources

    Microsoft Azure is the dominant cloud provider in enterprise environments, especially in organizations with existing Microsoft infrastructure. Azure security is a high-value skill.

    **Official Training**
    - **Microsoft Learn** ([learn.microsoft.com](https://learn.microsoft.com)) — Microsoft's free learning platform includes structured learning paths for Azure security, covering identity and access management, network security, threat protection, and governance. Many paths align directly to certification exams.
    - **AZ-500: Microsoft Azure Security Engineer** — The core Azure security certification. It validates your ability to manage identity and access, implement platform protection, secure data and applications, and manage security operations in Azure. Microsoft Learn's free study paths map directly to AZ-500 objectives.

    **Research and Benchmarks**
    - **Microsoft Security Blog** ([microsoft.com/en-us/security/blog](https://www.microsoft.com/en-us/security/blog)) — Microsoft's security researchers publish threat intelligence, Azure-specific attack analysis, and detection guidance. Essential reading for staying current on cloud threats.
    - **Azure Security Benchmark** — Microsoft's comprehensive set of security recommendations for Azure services. Organized by control category, it tells you exactly how to configure each Azure service securely and maps to frameworks like CIS and NIST.
  </Tab>
  <Tab title="GCP">
    ### GCP Security Training Resources

    Google Cloud Platform is the third major cloud provider and is particularly strong in data analytics, Kubernetes, and AI workloads. GCP security skills are increasingly in demand.

    **Official Training**
    - **Google Cloud Skills Boost** ([cloudskillsboost.google](https://cloudskillsboost.google)) — Google's official learning platform offers free and low-cost labs through Qwiklabs. Security-focused learning paths cover IAM, VPC Service Controls, Security Command Center, and logging. Many labs give you access to a real GCP environment at no cost.

    **Certifications**
    - **Professional Cloud Security Engineer (PCSE)** — Google's dedicated cloud security certification validates your ability to design and implement secure infrastructure on GCP. It covers IAM, network security, data protection, Kubernetes security, and incident response. Google Cloud Skills Boost offers dedicated preparation paths aligned to exam objectives.

    **Recommended Starting Path**
    Start with the "Security Engineer Learning Path" on Google Cloud Skills Boost, which bundles the most relevant courses and labs in sequence. Completing the path also earns you completion badges visible on your public Google Cloud profile.
  </Tab>
</Tabs>

## Cloud-Agnostic Resources

These resources apply across all three major cloud platforms and are valuable regardless of which provider your organization or employer uses.

<CardGroup cols={2}>
  <Card
    title="Cloud Security Alliance"
    href="https://cloudsecurityalliance.org"
    icon="cloud"
  >
    The CSA is the leading organization for cloud security standards and research. It publishes the CCSK (Certificate of Cloud Security Knowledge) certification — a vendor-neutral credential recognized across the industry — along with free research, the Cloud Controls Matrix, and the Security Guidance for critical areas of cloud computing.
  </Card>
  <Card
    title="CCSP Certification Resources"
    href="https://isc2.org/certifications/ccsp"
    icon="certificate"
  >
    The Certified Cloud Security Professional (CCSP) from ISC2 is the senior cloud security certification, covering cloud architecture, design, operations, and legal compliance across all providers. It's the cloud equivalent of the CISSP and is highly valued in enterprise and consulting roles.
  </Card>
  <Card
    title="CloudGoat"
    href="https://github.com/RhinoSecurityLabs/cloudgoat"
    icon="github"
  >
    Rhino Security Labs' vulnerable-by-design AWS environment is one of the best hands-on tools for learning cloud attack and defense. Each scenario teaches a specific attack path — privilege escalation, SSRF via metadata, overly permissive roles — with walkthroughs available if you get stuck.
  </Card>
  <Card
    title="HackTricks Cloud"
    href="https://cloud.hacktricks.xyz"
    icon="book"
  >
    HackTricks Cloud is a free, community-maintained wiki covering cloud pentesting techniques across AWS, Azure, GCP, and Kubernetes. It's organized as a practical attacker reference — ideal for understanding how cloud misconfigurations are exploited in the real world.
  </Card>
</CardGroup>

<Warning>
  Always use a dedicated, isolated practice account for cloud security labs — never run attack simulations, vulnerable environments, or tools like CloudGoat against a production account. Cloud misconfigurations and lab environments can incur unexpected charges and, more critically, real security incidents. Create a separate AWS, Azure, or GCP account exclusively for learning and set a billing alert to avoid surprise costs.
</Warning>

<Tip>
  AWS's free tier gives you twelve months of access to a generous set of services at no cost — including EC2, S3, Lambda, IAM, and CloudWatch. This makes it the ideal starting point for building and practicing cloud security concepts hands-on. Spin up a free tier account, work through the Flaws.cloud challenge, and experiment with IAM policy configurations before moving to more complex labs.
</Tip>
