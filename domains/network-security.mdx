Network security forms the backbone of cybersecurity operations. Build from protocol fundamentals into packet analysis, network forensics, telemetry correlation, and detection engineering.

## Key skills to learn

- **TCP/IP fundamentals** — addressing, subnetting, routing, TCP/UDP, DNS, HTTP, TLS, and common protocol behavior.
- **Packet analysis** — PCAP structure, Wireshark display filters, endpoints, conversations, streams, and protocol fields.
- **Network forensics** — reconstruct activity, correlate evidence, extract artifacts safely, and document limitations.
- **Firewall and segmentation concepts** — stateful filtering, rule ordering, VLANs, DMZs, and least-privilege routing.
- **IDS/IPS analysis** — interpret and tune Suricata or Snort alerts and connect signatures to packet evidence.
- **Enterprise telemetry correlation** — move between Security Onion, Arkime, Suricata, and SIEM evidence.

## Recommended learning order

<Steps>
  <Step title="Build networking foundations">Learn addressing, routing, TCP/UDP, DNS, HTTP, and TLS before interpreting complex captures.</Step>
  <Step title="Learn packet analysis">Use Wireshark to identify endpoints, protocols, conversations, DNS activity, and application metadata.</Step>
  <Step title="Practice network forensics">Investigate DNS, web sessions, periodic communications, transferred artifacts, and timelines.</Step>
  <Step title="Correlate defensive telemetry">Connect packet observations to Suricata/Snort alerts, Security Onion, Arkime, and indexed SIEM data.</Step>
  <Step title="Engineer and validate detections">Use packet evidence to determine what a network detection can reliably observe and test it against authorized lab traffic.</Step>
</Steps>

## Hands-on Network Forensics course

<Card title="Network Forensics Learning Path" href="/training/network-forensics/index" icon="network-wired">
Progress through seven applied labs from Wireshark foundations to a Security Onion and Arkime-correlated capstone investigation.
</Card>

| Lab | Capability |
| --- | --- |
| 1. Packet Analysis Foundations | Scope PCAPs, filter traffic, inspect endpoints and conversations, and reconstruct streams. |
| 2. DNS Investigation | Reconstruct name resolution and correlate DNS with subsequent network activity. |
| 3. HTTP, TLS, and Web Traffic | Analyze plaintext transactions and encrypted-session metadata. |
| 4. Beaconing Analysis | Characterize periodic communication and test competing explanations. |
| 5. File and Artifact Analysis | Export authorized objects, hash them, preserve provenance, and bridge into IOC/YARA workflows. |
| 6. Security Onion + Arkime | Pivot from alerts and sessions to packet evidence and correlate Suricata telemetry. |
| 7. Capstone | Conduct and report an end-to-end investigation with minimal guidance. |

## Practice progression

```text
Understand protocol behavior
        ↓
Obtain authorized traffic
        ↓
Filter and scope
        ↓
Reconstruct conversations
        ↓
Explain packet evidence
        ↓
Correlate IDS/session/SIEM telemetry
        ↓
Test competing explanations
        ↓
Build or validate a detection
```

<Tip>
Begin with traffic deliberately generated in an authorized lab. Knowing the expected behavior gives you immediate feedback about whether your packet interpretation is correct.
</Tip>
