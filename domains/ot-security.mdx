# ICS and OT security

Start with the protocols and operational constraints that make industrial environments distinct. Practice only in a simulator or an explicitly authorized lab.

| Resource | Use it for |
|---|---|
| [Awesome Industrial Protocols](https://github.com/Orange-Cyberdefense/awesome-industrial-protocols) | Identify common protocol families, their specifications, tools, and security considerations. |
| [SANS ICS training](https://www.sans.org/industrial-control-systems-security/) | Compare OT security learning tracks and course objectives. |

## Practice path

1. Pick one protocol such as Modbus or DNP3 and document its purpose, common ports, message types, and operational impact.
2. Capture or obtain safe lab traffic. Identify devices, function codes, and normal communication patterns.
3. Write a detection hypothesis for an unexpected command or destination.
4. State assumptions, likely false positives, and how an operator would validate the finding.

Continue with [Network Security](/domains/network-security) and [SIEM & Tools](/domains/siem-and-tools) for analysis workflows.
