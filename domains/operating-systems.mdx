# Windows and Linux foundations

Use these resources to build the operating-system fluency needed for log analysis, incident response, system hardening, and lab work.

## Windows and Active Directory

| Resource | Category | Level | Access | Focus | Practice outcome |
| --- | --- | --- | --- | --- | --- |
| [Populating Active Directory](https://petri.com/populate-active-directory-with-test-user-accounts/) | Windows / Active Directory | Intermediate | Free article | Create synthetic test users in a lab directory | Build a repeatable AD dataset for authentication and detection exercises. |
| [Latest Windows Server training on Microsoft Learn](https://techcommunity.microsoft.com/blog/itopstalkblog/latest-windows-server-training-on-ms-learn/2093132) | Windows Server | Beginner → Intermediate | Free | Microsoft’s 2021 roundup of Windows Server 2019 learning modules | Use it as a starting index, then follow the current Microsoft Learn paths below. |
| [Windows Server deployment, configuration, and administration](https://learn.microsoft.com/en-us/training/paths/windows-server-deployment-configuration-administration/) | Windows Server | Intermediate | Free | Deployment, secure administration, Windows Admin Center, Server Manager, PowerShell remoting | Build and document a securely administered Windows Server lab. |
| [Secure Windows Server infrastructure](https://learn.microsoft.com/en-us/training/paths/secure-windows-server-infrastructure/) | Windows Server Security | Intermediate | Free | Security baselines, LAPS, PAWs, AD security, Defender, audit policy | Harden a Windows Server/AD lab and record the controls you applied. |
| [Under the Wire](https://underthewire.tech/) | PowerShell | Beginner → Intermediate | Free | PowerShell wargames | Use commands and pipelines to solve progressively harder tasks. |

<Note>
  The TechCommunity article is still useful as an index, but it was published in 2021 and focuses on Windows Server 2019. Prefer the current Microsoft Learn paths for hands-on study because they are actively maintained and now include Windows Server 2025 content.
</Note>
