# Windows and Linux foundations

Use these resources to build the operating-system fluency needed for log analysis, incident response, system hardening, and lab work.

## Windows and Active Directory

| Resource | Focus | Practice outcome |
|---|---|---|
| [Populating Active Directory](https://petri.com/populate-active-directory-with-test-user-accounts/) | Create synthetic test users in a lab directory | Build a repeatable AD dataset for authentication and detection exercises. |
| [Windows Server learning on Microsoft Learn](https://techcommunity.microsoft.com/blog/itopstalkblog/latest-windows-server-training-on-ms-learn/2093132) | Server administration and identity fundamentals | Configure a Windows Server lab and document key roles. |
| [Under the Wire](https://underthewire.tech/) | PowerShell wargames | Use commands and pipelines to solve progressively harder tasks. |

## Linux and shell

| Resource | Focus | Practice outcome |
|---|---|---|
| [OverTheWire wargames](https://overthewire.org/wargames/) | Linux command line, permissions, text processing | Complete Bandit and keep a command journal. |
| [Linux roadmap](https://roadmap.sh/linux) | A map of core Linux concepts | Identify gaps in processes, networking, services, and permissions. |

<Note>Use disposable VMs and synthetic accounts for the Active Directory exercises.</Note>
