# SIEM and security analysis tools

Move from tool orientation to a small, reproducible investigation. Use sample or authorized telemetry and record the query, evidence, and conclusion.

| Tool | Resource | Learning objective |
|---|---|---|
| Arkime | [Arkime learning resources](https://arkime.com/learn) | Import a sample PCAP, filter sessions, inspect protocol metadata, and pivot to packet detail. |
| Splunk | [Splunk eLearning](https://education.splunk.com/elearning) | Search events, extract fields, build a timeline, and save a useful search. |
| Splunk | [Splunk Security Essentials documentation](https://docs.splunk.com/Documentation/SSE) | Explore security use cases and map a detection idea to required data. |
| Security Onion | [Security Onion documentation](https://docs.securityonion.net/) | Navigate alerts, Hunt, PCAP, and detections; write a short investigation summary. |

## Suggested sequence

1. Choose one sample dataset and write three investigative questions.
2. Find the relevant events or sessions with each tool's search interface.
3. Record filters, timestamps, source data, and the evidence behind your conclusion.
4. Create or tune one detection and test it against representative benign and suspicious activity.

See [Network Security](/domains/network-security) for packet-analysis resources and [Python for DCO](/training/python/dco-detection-engineering) for automation projects.
