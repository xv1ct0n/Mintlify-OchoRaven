# AI and machine learning for security

Use AI and ML as tools for specific analyst problems: data preparation, baselines, prioritization, and evaluation. Keep a simple non-ML baseline so improvements can be measured.

| Resource | Focus | Practical output |
|---|---|---|
| [SecurityNik Data Science and ML](https://github.com/SecurityNik/Data-Science-and-ML/tree/main) | Security-focused notebooks and data science examples | Reproduce an example, explain its features and labels, and evaluate errors. |
| [LM Studio](https://lmstudio.ai/) | Local model experimentation | Test a local summarization task with synthetic or sanitized telemetry and record failure cases. |

Start with the [Python Training Path](/training/python/index), then build a small dataset with documented provenance and compare a heuristic against a model. Avoid putting sensitive operational data into external services without authorization.
