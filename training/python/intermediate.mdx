# Intermediate — Security Automation

**Goal:** Move from individual scripts to reusable analyst tools that interact with APIs and larger datasets.

## Concepts to learn

- Classes and practical object-oriented design — [W3Schools classes](https://www.w3schools.com/python/python_classes.asp)
- Modules and packages — [Python modules tutorial](https://docs.python.org/3/tutorial/modules.html)
- Type hints — [Python typing](https://docs.python.org/3/library/typing.html)
- Comprehensions and generators — [Python data structures](https://docs.python.org/3/tutorial/datastructures.html)
- Regular expressions — [W3Schools RegEx](https://www.w3schools.com/python/python_regex.asp)
- `argparse` — [Python argparse tutorial](https://docs.python.org/3/howto/argparse.html)
- HTTP and REST APIs — [Python urllib.request](https://docs.python.org/3/library/urllib.request.html)
- Authentication and environment variables — [Python os.environ](https://docs.python.org/3/library/os.html#os.environ)

## Intermediate checkpoint

You are ready for Advanced when you can independently build a tool that:

- consumes a documented API;
- separates configuration from code;
- has useful logging and exception handling;
- uses functions/modules with clear responsibilities;
- contains automated tests;
- produces predictable structured output; and
- can be used by another analyst by following its README.
