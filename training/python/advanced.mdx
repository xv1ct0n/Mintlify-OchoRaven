# Advanced — Engineering Security Tools

**Goal:** Build security tooling that is maintainable, testable, observable, and suitable for team use.

## Concepts to learn

- Advanced typing and interfaces — [Python typing](https://docs.python.org/3/library/typing.html)
- Dataclasses and data models — [Python dataclasses](https://docs.python.org/3/library/dataclasses.html)
- Iterators, generators, decorators, and context managers — [Python functional programming HOWTO](https://docs.python.org/3/howto/functional.html)
- `asyncio` and controlled concurrency — [Python asyncio](https://docs.python.org/3/library/asyncio.html)
- Queues and producer/consumer patterns — [Python queue](https://docs.python.org/3/library/queue.html)
- Performance profiling — [Python profiling](https://docs.python.org/3/library/profile.html)
- Structured logging — [Python logging cookbook](https://docs.python.org/3/howto/logging-cookbook.html)
- Secure configuration and secrets handling — [Python secrets](https://docs.python.org/3/library/secrets.html)
- Packaging with `pyproject.toml` — [Python pyproject.toml guide](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/)
- Automated linting, formatting, and testing — [pytest getting started](https://docs.pytest.org/en/stable/getting-started.html)
- CI/CD fundamentals — [GitHub Actions quickstart](https://docs.github.com/en/actions/get-started/quickstart)
- Containerization — [Docker Python guide](https://docs.docker.com/guides/python/)
- API service design — [FastAPI tutorial](https://fastapi.tiangolo.com/tutorial/)
- Data validation — [Pydantic concepts](https://docs.pydantic.dev/latest/concepts/models/)
- Retry/backoff strategies — [Python time.sleep](https://docs.python.org/3/library/time.html#time.sleep)
- Metrics and operational health — [Python logging HOWTO](https://docs.python.org/3/howto/logging.html)

## Advanced checkpoint

A completed advanced project should be understandable and usable by someone who did not write it. Your repository should contain:

```text
project/
├── README.md
├── pyproject.toml
├── src/
├── tests/
├── examples/
├── .gitignore
└── Dockerfile        # when applicable
```

You should be able to explain architectural decisions, failure modes, security considerations, test strategy, and operational limitations.
