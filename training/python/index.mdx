# Python Training Path

Learn Python by building capabilities that resemble the work performed by security analysts, threat hunters, incident responders, and detection engineers.

<Info>
This path is designed around **learn → build → explain → improve**. Each stage introduces language concepts, then requires you to apply them in a practical project rather than only completing syntax exercises.
</Info>

## What you will be able to do

By completing the full path, you should be able to:

- Read, modify, and write Python with confidence.
- Parse JSON, CSV, JSONL, and common security telemetry formats.
- Automate repetitive analyst workflows.
- Query REST APIs and safely handle authentication, errors, pagination, and rate limits.
- Transform raw telemetry into useful analyst context.
- Build and test detection-engineering utilities.
- Validate detection logic against representative datasets.
- Structure Python projects with modules, configuration, logging, tests, and documentation.
- Build a portfolio of security-focused projects that demonstrate practical capability.

## Recommended workflow

<Steps>
  <Step title="Learn the concept">
    Use the linked documentation and training resources to understand the assigned Python concepts.
  </Step>
  <Step title="Build without copying">
    Implement the project yourself. Reference documentation, but avoid copying a completed solution.
  </Step>
  <Step title="Test against realistic input">
    Use sanitized, synthetic, or lab-generated security data. Confirm expected output and failure behavior.
  </Step>
  <Step title="Document your reasoning">
    Write a README explaining the problem, design, usage, limitations, and security considerations.
  </Step>
  <Step title="Refactor">
    Improve naming, functions, error handling, tests, logging, and maintainability after the first working version.
  </Step>
</Steps>
