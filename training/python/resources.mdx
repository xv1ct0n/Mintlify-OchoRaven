# Python learning resources

Choose one primary course, then practice each concept in the [beginner projects](/training/python/beginner). The listed platforms have different access models; check their current free and paid offerings before enrolling.

## Free concept-by-concept starting points

- [W3Schools Python tutorial](https://www.w3schools.com/python/) — short explanations, examples, and in-browser exercises for syntax, control flow, functions, data structures, classes, files, and exceptions.
- [W3Schools Python exercises](https://www.w3schools.com/python/python_exercises.asp) — practice each foundation topic after reading its stage or project lesson.
- [Official Python tutorial](https://docs.python.org/3/tutorial/) — deeper explanation of language fundamentals and modules.
- [Python standard library](https://docs.python.org/3/library/) — task-specific references for `pathlib`, `json`, `csv`, `hashlib`, `datetime`, and concurrency.
- [Python packaging guide](https://packaging.python.org/) — environments, dependencies, and `pyproject.toml`.

The [Beginner](/training/python/beginner), [Intermediate](/training/python/intermediate), and [Advanced](/training/python/advanced) concept lists link directly to a free lesson for each topic. Every guided project also links its component lessons to relevant explanations.
