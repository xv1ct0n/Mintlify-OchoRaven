# Python learning resources

Choose one primary course, then practice each concept in the [beginner projects](/training/python/beginner). The listed platforms have different access models; check their current free and paid offerings before enrolling.

## Guided courses and references

| Resource | Best use |
|---|---|
| [Official Python tutorial](https://docs.python.org/3/tutorial/) | Canonical language reference and examples. |
| [futurecoder](https://futurecoder.io/) | Interactive lessons for a new programmer. |
| [Codecademy Python catalog](https://www.codecademy.com/catalog/language/python) | Guided exercises and course options. |
| [Coursera: Programming in Python](https://www.coursera.org/specializations/hands-on-python) | Structured specialization with hands-on assignments. |
| [Python Morsels](https://www.pythonmorsels.com/) | Short exercises for idiomatic code and deeper language fluency. |
| [JetBrains Academy: NumPy](https://plugins.jetbrains.com/plugin/18302-mastering-python-libraries--numpy) | Numerical array practice for later data work. |
| [JetBrains Academy: Data Visualization with Python](https://academy.jetbrains.com/course/27941) | Visualizing and communicating data. |
| [Advanced Python for Data Science and ML roadmap](https://roadmap.sh/ai/course/advanced-python-for-data-science-and-machine-learning-1771892821214) | A later-stage topic map after the fundamentals. |

## Apply the learning

1. Build the [IOC Normalizer](/training/python/projects/ioc-normalizer).
2. Extend it with a CSV export and tests.
3. Build the [Authentication Log Summarizer](/training/python/projects/auth-log-summarizer) and [File Hash Inventory](/training/python/projects/file-hash-inventory).
4. Record inputs, outputs, edge cases, and limitations in each project's README.
